## Overview

### 1. Locale File Renaming
- `src/i18n/zh-HK.ts` → `src/i18n/zh-hk.ts`

- Updated import in `src/i18n/index.ts`

### 2. Locale Definition Update
- Updated `src/i18n/index.ts` LOCALE_DEFINITIONS array
- Added `zh-hk` locale with:
  - `code: "zh-hk"`
  - `label: "繁體中文 (香港)"`
  - `dateLocale: "zh-hk"`
  - `dictionary: zh_hk`

### 3. Environment Configuration
- `.env` updated with `BOT_LOCALE=zh-hk`
- Enables Cantonese/Traditional Chinese UI

### 4. Documentation
- `CHANGELOG.md` created at repository root
- `docs/bencrox-fork/2026-Oct-15.md` created for detailed tracking

## Technical Details

### Locale Resolution Fix
The lowercase `zh-hk` now correctly matches the dictionary key via `resolveSupportedLocale()` function, which normalizes input to lowercase before lookup. Previously, `zh-HK` (mixed case) caused a mismatch, forcing fallback to English `zh`.
